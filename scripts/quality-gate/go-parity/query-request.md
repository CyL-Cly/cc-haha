# Original-request single-round query integration

This boundary connects actual Source `src/query.ts:225 query()` → `src/query/deps.ts:35 productionDeps().callModel` → `src/services/api/claude.ts:845 queryModelWithStreaming()` → pinned Anthropic SDK → actual private HTTP socket with the independent Go chain `queryloop.Run` → `Snapshot(Round.History)` → lossless `protocol.JSONObject` → `modelyield.Run` → shared `requestretry.Open` → one `requestcontext.Prepare` → independently resolved original-env client → raw Messages HTTP → shared stream-history Controller → original assistant history. The Go candidate receives only original history/system JSON, declared model/interaction/output-limit inputs, the frozen device/session/runtime identity, allowlisted request environment and the response wire. Both fixture entry points reject prepared-request/body/path shortcuts. Source-observed requests and decisions never become Go inputs.

The three ordinary single-response cases exercise headless (`sdk`), interactive (`repl_main_thread`), and original UTF-16/unrepresentable integer history. Both query profiles resolve `fixture-model`, thinking disabled, output limit 32000, empty native tools, SDK betas and managed policies, no experiments/OAuth/cloud routing, and no automatic retry/fallback. Source executes its production query, compaction, normalization, hooks, auth selection/client construction and SDK; the wrapper only observes original model-history inputs and final fetch inputs, delegates the production model generator, and calls the granted actual loopback fetch. The secure-store adapter returns observable null and exact external managed-policy reads return observable absence before production imports. Date/UUID calls are frozen after private bootstrap.

Strict comparison includes complete signed request body bytes and pathname/query, every resolved pre-fetch header, yield-time and final assistant/stream-event JSON, original returned history and allocation order, terminal result, stderr and actual HTTP request count. The parent additionally verifies that each explicitly resolved header and exact body/path reaches the actual socket on each side. Automatic Bun/Go HTTP transport headers remain side-specific evidence; their wire equality is not claimed. Outer observation object key order is semantically compared, while body and message JSON are opaque exact strings.

The native `TestActualSourceOriginalRequestIntegration` in queryloop reuses the exact candidate fixture driver and three actual Source goldens. It independently constructs the request and checks the complete observed contract plus the actual HTTP request against those Source bytes. The fixture driver's source is testdata, not a new production host policy.

Source and Go guards reject missing/public origins, missing explicit fixture profile, mismatched HOME and a Source-prepared request shortcut. Source negative checks install a production-import tripwire; both sides preserve a private sentinel. The strict comparator is also challenged with deliberate body-whitespace, header, path, history, yield and allocation changes. All builds use pinned Bun 1.3.14/Go 1.25.7 and verified offline dependency seed/private HOME/cache.
