# Initialized ordered-record reference contract

`protocol.JSONObject` must retain one top-level identity when an initialized value is passed or copied. Source cache-safe helpers copy the history array and retain each original user message reference. Inserting, deleting or deleting and readding a property through the original reference must therefore change the retained record's enumeration as well as its values. The old Go record shared its map but copied the order slice header, so these two views diverged.

The implementation stores the order and raw values in one private state. `Clone`, `Get`, `OwnProperties` and `Assign` retain their independent raw-byte snapshots. A zero/null record stays uninitialized; decoding a replacement rebinds the receiver rather than replacing every existing alias. Mutation must be coordinated by the owning caller. This does not introduce nested JSON identity, a lock, or concurrent mutation guarantees.

`object-reference.fixture.ts` executes actual Source `handleStopHooks`, `createCacheSafeParams`/`getLastCacheSafeParams`, side-question preparation and model normalization in an external production profile with no hooks or tools. It accepts only original `home`, `kind`, `userSource` and `assistantSource`. Before importing production, it requires a disposable HOME/config, pinned Bun1.3.14, production NODE_ENV, UTC and the explicit `CC_HAHA_CACHE_IDENTITY_PROBE=1` marker. Use the existing sandbox environment and absent-managed/empty-native adapters; never run against the user's HOME.

The original raw user and assistant inputs and captured Source provenance live in `backend/internal/protocol/testdata/object_reference_source_contract.json`. Source was independently executed and strictly replayed for both actual Factory construction and a legacy raw record: four clean children, six observation points each. The primitive operations after the cache save are explicit probe instructions. No reachable production late-property producer was confirmed by the bounded search.

The native regression reconstructs the Factory/raw record and retained value alias, then compares its property bytes and enumeration with the twelve captured Source observations. It does not execute the Go StopHooks/side-question host or certify its entire request, transcript writer, fork lifecycle or nested assistant references. Additional native cases check numeric and UTF-16 own-key order, undefined/null slots, assign/clone/raw-copy isolation, zero/null and decoder rebinding, and independent concurrent read snapshots. Changing these fixtures does not authorize recapturing expected values from Go.

Broad downstream checks and the final aggregate must use the actual applied candidate inputs before this can be called current evidence. Temporary overlay/module-copy results remain candidate-only; old failures remain retained.
