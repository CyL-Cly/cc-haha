# Retained Skills request normalization

This slice consumes original persisted `invoked_skills` and `skill_listing` payloads in shared request preparation. It preserves duplicate/empty names and original array order; it does not substitute the restored invoked-skills state map, read a registry, accept rendered reminder text, or accept Source-prepared history/body/schema.

`attachments.ReorderForAPI` performs stable backward bubbling before virtual-message filtering. Assistants and users whose first block is `tool_result` stop bubbling. `Project` calls the shared exact JavaScript coercion and user Factory, with raw UTF-16 content and UUID→Date allocation order. `MergeIntoUser` calls the existing attachment-specific user/tool-result merge and restores ordered original envelope/message slots. Generic user merging stays in requestcontext's ordinary-user branch. Shared `Prepare` performs this once, before pairing and per-attempt mapping, cache overlays and signed CCH bytes.

Malformed supported renderer inputs return `MalformedAttachmentError`; shared normalization catches only this type and drops that attachment like Source. The direct projector still exposes the original TypeError class/message/MessageJSON. Unsupported attachment kinds and unsupported host/shape boundaries return `CapabilityError` and cannot be swallowed as malformed. In particular nonarray collections with an own `map` override are an explicit unported runtime diagnostic boundary. Inputs deeper than the shared raw-JSON/ordered-record validators' supported domain fail closed, rather than becoming assumed equivalent.

The shared exact coercion covers missing→undefined, null, number/boolean/array/ordinary-object template conversion, lone UTF-16, numeric overflow, and own noncallable `toString` failures. It is the error-propagating API; changing the old nonthrowing string helper's consumers is outside this slice.

Evidence is separated by boundary:

- `retained-skills.test.ts`: original raw payload projection and original history through the actual exported Source normalizer + actual pairing versus production Go `Prepare.NormalizedHistory`. Inputs include positional/virtual/tool-result distinctions, duplicates, falsey/truthy values, missing/null/non-string fields and surrogate/coercion errors. It runs Source self replay, exact JSON-string observations, allocation traces, comparator mutations, and pre-import capability guards. Error stacks remain raw Source-only diagnostics; stack/source-excerpt compatibility is pending.
- `retained-skills-http.test.ts`: original tool-free histories run through actual Source queryModelWithStreaming/client/auth/SDK and independent Go requestretry.Open→Prepare→BuildAttempt→RawHTTP1Exchange. A real private socket supplies 500→429 with duplicate Retry-After→200. It compares full signed request body, path, all resolved pre-fetch headers, notices, delays, paired history, ID counts, client/key reuse and yields. Wire body/path and each resolved header are separately checked against the physical capture. Automatic Bun fetch headers are retained Source-only evidence, not normalized away into a full-wire claim. Source hooks observe and delegate original functions. Both sides receive the same original raw environment/history; no captured request is injected.
- Native `attachments` tests consume a checked-in actual Source contract produced from original raw inputs, plus independently specified capability/merge/input-preservation failures. Expected output is never generated by the candidate Go implementation.
- Existing resume first-request integration closes restored original Skills messages→shared Prepare→real HTTP; its owner maintains that separate fixture and result.

Retained projection does not require SkillTool to be available: the same original history is observed tool-free and with actual native Write. Full physical retry here remains the existing tool-free profile. Native-tool request/loop integration and all main entry/default-transport rollout assertions are separate evidence.

New Skills listing creation/discovery/MCP registry, process-owned suppression and sent-name maps, prompt formatting budgets, SkillTool execution/schema, compact-generated attachments, alternate HISTORY_SNIP/tool-search/sermon features, enabled-debug logging, unported attachment kinds, default transport, complete CLI/Server/shared Harness and live Benchmark non-regression remain outside this slice. Deterministic fixture credentials authorize no live provider calls.
