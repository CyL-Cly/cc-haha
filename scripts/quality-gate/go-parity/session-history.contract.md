# Session location and raw CLI transcript recovery

This component ports the filesystem branch of `SessionService.findSessionFilesFromFiles` / `findSessionFile` (`src/server/services/sessionService.ts`) and the real explicit-JSONL resume reader `loadMessagesFromJsonlPath` (`src/utils/conversationRecovery.ts:510`). Its Source call chain is `loadTranscriptFile` → terminal user/assistant leaves → newest non-sidechain leaf → `buildConversationChain` → parallel assistant/tool-result recovery → `removeExtraFields`.

`sessionlocator.Service.FindFiles` and `FindFile` independently enumerate `<config>/projects/<project>/<sessionId>.jsonl`, prioritize real conversation content over newer placeholder files, then compare mtime and paths. Candidate stat/read errors are skipped as in Source. The constructor requires explicit config, real directory/stat operations, the shared `sessionstore.Reader` and admission `Budget`, and an independent collation callback. The oracle starts the actual public Source service with its default filesystem configuration; it does not inject a Source-selected file into Go.

`sessionhistory.Loader.LoadMessagesFromJSONLPath` returns complete serialized conversation envelopes and the selected leaf's session identity. It strips only `parentUuid` and `isSidechain` at this Source boundary. It retains complete image/tool payloads and future fields. These envelopes are the serialized history before `loadConversationForResume` deserialization, hooks and state restoration; they are neither React display messages nor proof of a complete CLI resume. `LoadTranscriptFile` retains raw parent records, session metadata maps, file/attribution snapshots, replacement records and context-collapse entries. Its Map/Set-to-array JSON view is a test inspection adapter, never a new disk format.

The loader requires actual files/stat/read, explicit precompact-disable and leaf-prune policy callbacks, a date parser, collation and a diagnostic sink. A production bootstrap must supply the real policies and diagnostic service. The fixture captures actual Source analytics and error logs; Go records the matching event payloads. Original Source error stacks remain in ignored artifacts and are not asserted equivalent to Go stacks. Final bytes go through the shared JavaScript JSON serialization boundary, preserving Source double rounding, overflow-to-null, lone UTF16 units, duplicate keys and property order. Callers must use that boundary when serializing raw envelopes.

The CLI full reader intentionally has no server display record limit or server full-history truncation. It reuses `sessionstore.FileSystem` and shared protocol codecs; imposing the server's 8 MiB record omission here would change a subsequent query. The actual large-file Source optimizations are ported: 5 MiB gate, 1 MiB reads, compact search bounds, short seam carry behavior, last attribution snapshot at EOF, 64 KiB session-metadata scan, raw parent/UUID prefilter, nested-UUID disambiguation, half-byte pruning gate, keep-all-leaves policy and kill switch. Progress bridges, preserved-segment endpoint relinks/usage zeroing, stale segment pruning, snip gap relinks, parent-cycle diagnostics and parallel tool-result siblings run on the original persisted records. No transcript is migrated or rewritten by this component.

The differential corpus initializes the same private files independently for Source, Source replay and Go. It compares exact result bytes, diagnostic events and final input bytes. It includes complete/partial EOF, malformed lines/null partial reducers, all metadata maps, forks, progress, duplicate UUIDs, future fields/numeric lexemes, lone UTF16, BOM/CRLF/invalid UTF8, auxiliary leaves/cycles, compact seam variants, snapshots, dead forks with nested UUIDs, 9 MiB records, replacements, snips, parallel tool siblings/results, native TypeErrors, candidate priority/order and append/rewrite mutants. Both fixtures reject HOME/config/input/output/project and missing-parent symlinks before touching external sentinel bytes. Source installs filesystem/native/process/network/credential capability guards before production imports; no grants are supplied. Go's fixture uses canonical private-path guards and hermetic dependencies; this is process code isolation, not a general kernel network sandbox.

The ordinary suite writes captures only under ignored `artifacts/go-parity/session-history/`. Frozen native regression contracts are refreshed only by the separate explicit command below, before source freeze. It requires exact Bun 1.3.14 and updates the backend golden only after the complete Source replay/Go differential passes. The capture script is never imported by the unified corpus.

```sh
bun scripts/quality-gate/go-parity/session-history.capture.ts --capture-frozen-native-golden
```

Remaining integration and compatibility boundaries are explicit:

- Go Server API routing, desktop message pages/evidence/UI projection and complete desktop history are not connected by this package. `SessionService.getSessionMessagesWithEvidence` uses a different bounded display projection and must not consume these raw CLI envelopes as display rows.
- SQLite index hydration/mutation epochs/cooldown, cached metadata lookup, live/background-session exclusion, project/worktree mapping, `getLastSessionLog` selection/cache priming, `--continue`, hooks, `deserializeMessages`, malformed-attachment handling, interruption state and snapshot/replacement restore are separate Source business that still needs porting/wiring. An already-known SID can use the locator here; this does not select the most recent CLI conversation.
- Date parsing declares the existing independent ISO/RFC UTC profiles and rejects unsupported legacy/local-timezone Date.parse inputs. Complete host ICU/default-locale/lone-surrogate collation is not established by the independent English collator's tested profile. Invalid UTF8 Go paths are rejected by the loader; invalid native filenames and Windows/macOS/Linux filesystem behavior require their native matrix.
- Native JSON depth beyond Go's current validator limit, JSONL parser shapes not in the actual profiles, malformed timestamp localeCompare receivers and arbitrary Bun noniterable object-error rendering remain unfinished. Nonempty object snip iterators return an explicit unsupported error; the supported malformed profiles match observed Bun 1.3.14 errors. A removed-parent snip cycle makes Source nonterminate; Go rejects it explicitly rather than claiming matching successful recovery.
- Performance and peak-memory equivalence to Bun's optimized sink are not established by functional/race/coverage checks. Source stack equivalence and real end-to-end next-provider-request integration remain pending. No live model, real credentials, user config, desktop build or cross-host native run is used as evidence here.
