# Prepare the real Source parent

Run this only after the final ordinary CLI, complete original quality gate and four asset roles have genuine evidence on the same candidate inputs. This producer is unscored; it does not replace any of the 120 pairs.

Create a fresh, empty, owned0700 canonical directory under `/private/tmp`. Supply an explicitly selected owned0600 file containing only the raw DeepSeek token, outside the model allocation. Do not supply a Claude settings JSON or use OAuth.

```sh
python3 -B scripts/perf/source-parent-recorder/record_source_parent.py \
  --allocation /private/tmp/FRESH_EMPTY_PARENT_ALLOCATION \
  --source-root /absolute/frozen-main/repository \
  --go-binary /absolute/final/ordinary-cli \
  --candidate-evidence /absolute/final/candidate-evidence.json \
  --bun /absolute/pinned-bun \
  --key-file /absolute/private/raw-token-0600 \
  --allow-live
```

The five producer files must be present in the completed candidate input snapshot. They and the normal benchmark interfaces are sampled before and after. There is no generated `preparation.json` authorization dependency.

The worker verifies that same candidate, Source dependencies and Bun, then uses an anonymous ready FD and a separate anonymous credential FD. The supervisor admits one credential capability only after the exact ready frame and EOF; the key never enters the saved environment or argv. Rotation, output redaction, abnormal exit, incomplete streams or unsafe cleanup prevents freezing.

The producer invokes the ordinary frozen Source CLI through the existing live wrapper and transparent official DeepSeek transport. It records the actual URL value used by fetch. After joined completion it checks the public SID, physical user/assistant SIDs, complete assistant marker and identical original/copy bytes. Its version2 `frozen-parent-receipt.json` binds the actual supervision, public output, transport files and normal producer code identities. These evidence receipts detect mistakes and stale inputs; they are not signed attestations against an author who fabricates a fully consistent evidence set.

Use a different fresh0700 formal allocation. The normal benchmark command additionally requires:

```sh
--parent-transcript /private/tmp/QUALIFIED_PARENT_ALLOCATION/frozen-parent.jsonl \

```

Omit `--pilot` for formal120. The runner revalidates the entire parent chain before reading the key, on every pair boundary, and at completion. Old unbound parent receipts and pilot exit0 cannot authorize scored calls. Preserve every failed allocation; do not rewrite its history or retry a partial pair selectively.
